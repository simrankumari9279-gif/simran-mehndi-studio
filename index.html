🌿 What is Mehndi Booking?

Mehndi Booking is a simple and convenient platform created to make mehndi booking easier for customers in Jamshedpur.

Customers can choose from different mehndi packages, select their preferred design and submit a booking request online.

We offer Simple, Arabic, Bridal and Wedding Mehndi options. Custom designs are also available according to the selected package category.

📌 Booking Process

1

Customer website par apni details, booking date, package aur event location fill karke booking request submit kar sakta hai.

2

Booking request submit hone ke baad Pending / Waiting status mein jaati hai.

3

Admin booking ki details aur date availability check karta hai.

4

Booking accept hone par status Approved kiya jaata hai.

5

Agar booking accept nahi ho sakti, status Rejected kiya jaata hai.

6

Customer apni Booking ID + Phone Number se website par booking status check kar sakta hai.

7

Status update hone par customer ko WhatsApp ke through information di ja sakti hai.
